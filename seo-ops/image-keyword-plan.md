# Image keyword plan (BesteIPTVNederland)

**Market:** Nederland · language `nl-NL`  
**Rule:** every image gets phrases that fit **its page**. Do not paste the same keyword list on every file.

## What each image has

1. Dutch filename
2. Site `alt` (HTML)
3. Keywords injected in the image file (EXIF / IPTC / PNG text)
4. A row in `seo-ops/image-keyword-assignments.json`

## Where the main phrases go

Big terms (`iptv nederland`, `beste iptv nederland`, `iptv nederland kopen`) belong on the hero, the Open Graph image, and the main blog covers.

- `channels/*` → alt = channel name + IPTV Nederland
- `payments/*` → brand name + IPTV Nederland
- movie and series posters → title + IPTV Nederland
